# System Design Interview Lab V3

Static GitHub Pages learning site. Open `index.html` through an HTTP server, e.g. `python3 -m http.server 8000`, not file://. Each lesson is addressed via `?lesson=slug` and loads its own JSON. `mock.html` retains the previous rule-based simulator. Animations are conceptual, not benchmarks. Interview questions are illustrative, not verified company question banks. Add a lesson JSON and catalog entry to extend.
