04 / DATABASE INVESTIGATION

Investigate with SQL.

Truy vấn dữ liệu mẫu, kiểm tra kết quả và giải thích sự cố. SQLite chạy trong Web Worker của trình duyệt; không cần server cơ sở dữ liệu.

Results are checked against a small synthetic dataset, not all possible datasets. SQLite syntax differs from PostgreSQL and MySQL. First execution requires network access to load the pinned SQL.js runtime from cdnjs.
